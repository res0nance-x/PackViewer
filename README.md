PackViewer

PackViewer is an Android app for view pack files. A pack file (both encrypted and unencrypted) is a simple archive format that allows for random access. One can view all the contents of a file without first extracting it. This includes seeking or jumping backwards some minuters within a large video file for instance. This can be useful for creating collections or playlists of things and transfering them. A single pack file might represent an album, an anime series, all your holiday photoes, etc. You can append to the files, but the files are otherwise read-only.
